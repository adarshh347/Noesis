# Weltanschauung Frontend

Next.js frontend for visualizing philosophical insights with beautiful, interactive interfaces.

## Setup

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

The application will be available at `http://localhost:3000`

## Features

- **Note Creation**: Capture philosophical thoughts with rich text
- **Insight Extraction**: AI-powered analysis of themes, concepts, and connections
- **Visualizations**:
  - Interactive concept maps
  - Theme distribution charts
  - Pragmatic application flows
- **Beautiful UI**: Dark, philosophical theme with smooth animations

## Tech Stack

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Recharts (for charts)
- React Force Graph 2D (for network visualizations)
- Framer Motion (for animations)
